# 强势题材策略优化设计

## 目标

将 `dragon_board` 从主要依赖单日涨幅和成交活跃度的实验筛选，收敛为可解释的“强势题材观察”策略：候选必须同时具备价格强度、趋势基础、题材证据和可接受的追高风险。结果仍是观察候选，不输出确定性买入结论。

本次只修改选股策略及其直接依赖的筛选、评分和测试，不涉及定时任务、通知推送、部署或 Git 操作。

## 当前问题

1. `theme_heat` 与 `topic_alignment` 合计权重较高，但行业、概念或板块热度缺失时会回落到中性分，弱化了“题材”约束。
2. 盘中实时快照与上一交易日日线字段可能混用，昨日涨跌幅不能冒充今日强势。
3. `body_pct` 不保证来自当前未收盘 K 线，不能直接当作盘中上影线或冲高回落依据。
4. 快照源缺少 `volume_ratio` 时会整源失败；但静默使用旧日量比同样会制造错误信号。
5. 当前契约测试主要验证 YAML 可加载，没有覆盖题材缺失、数据陈旧和冲高回落反例。

## 方案

### 1. 数据可信度门控

- 为强势题材策略增加可执行的数据要求：盘中运行时，涨跌幅、成交额、换手率和量比必须来自当日快照。
- 若快照明确为上一交易日收盘数据，允许用于盘后复盘，但结果标记为 EOD，不宣称盘中强势。
- 当关键实时字段缺失时，本轮返回无可靠候选及明确降级原因，不用旧值或默认分凑数。
- 日线字段继续用于 MA20、MACD、60 日收益、20 日前高和历史量能判断，并与快照字段保持语义分离。

### 2. 题材确认

- `theme_heat` 和 `topic_alignment` 缺少真实板块或概念证据时使用低置信度分，而不是中性 50 分。
- 强势题材候选至少满足以下一种证据：有效板块热度、行业/概念与热点路线重合、可核验的题材催化。
- 题材字段全部缺失时不进入最终前五；单纯价格强势可由其他动量策略承接。
- 同一题材最多保留一只，继续使用组合集中度惩罚。

### 3. 强势但不过度追高

- 保留主板涨幅、成交额、换手、MA20、MACD、前高位置和 60 日过热限制。
- 将“当前快照涨幅”和“历史日 K 实体”分开，不再把历史 `body_pct` 描述为当日盘中实体。
- 有可靠盘中 OHLC 时，增加冲高回落和上影风险判断；没有可靠字段时不伪造该过滤条件。
- 对接近涨停、异常量比、高换手和题材降温分别产生风险标记，并在最终评分中扣分。
- 允许少于五只，宁缺毋滥。

### 4. 评分结构

- 评分仍以动量、活跃度、题材热度、题材匹配和流动性为主。
- 题材相关权重只有在证据完整时才能取得高分；缺失信息会降低最终置信度。
- LLM 只负责核验题材关联、催化真实性、失效条件和风险，不允许覆盖硬过滤，也不允许把低质量候选重新排入。
- 输出中保留因子分、数据源、快照时间、题材证据、风险标记和失效条件，便于复核。

## 错误与降级

- 实时源不可用：返回明确的数据源错误，不自动把上一交易日快照包装成盘中结果。
- 题材数据不可用：保留诊断信息，但强势题材策略不输出无题材证据的候选。
- 日线补充失败：由于趋势和前高是本策略必要条件，本轮失败，不降级为单日涨幅榜。
- LLM 失败：保留确定性因子排序，并标记 `ranking_mode=factor`；不影响硬过滤结果。

## 测试与验收

- 策略加载和字段契约测试。
- 有价格强度但无题材证据的股票不得进入最终候选。
- 有题材证据但趋势、流动性或数据质量不合格的股票必须被过滤。
- 昨日 EOD 快照不得标记为盘中强势。
- 缺少关键实时字段时返回明确降级原因。
- 高位追涨、异常换手和冲高回落反例产生对应风险标记或被过滤。
- LLM 失败后仍能输出一致的确定性因子排序。
- 相关选股回归测试通过，文档与 `docs/CHANGELOG.md` 同步更新。

## 不在本次范围

- 10:00/14:00 定时任务。
- 企业微信推送格式与渠道配置。
- 涨停时间、封单金额、开板次数、连板高度等需要新增外部数据源的真龙头识别。
- 自动交易、仓位管理或买卖指令。
- 远程服务器部署。
